# Student Management Database

## Description

This project is a MySQL Student Management Database created as part of a MySQL database fundamentals assignment.

The database stores information about students, courses, and student enrollments.

## Database Name

student_management

## Tables

### Students

Stores information about students including:

- Student ID
- First name
- Last name
- Age
- Email
- Gender
- Phone number

### Courses

Stores information about available courses.

### Enrollments

Stores information about students enrolled in different courses.
